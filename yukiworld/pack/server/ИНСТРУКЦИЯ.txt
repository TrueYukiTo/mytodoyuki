YukiWorld {VERSION} — серверная сборка (Minecraft 1.21.1, NeoForge 21.1.265)
=====================================================================

ШАГ 1. Скачать моды (на своём компьютере)
  Запусти «1_СКАЧАТЬ_МОДЫ.bat». Он скачает ~165 модов в папку mods
  (5–15 минут, проверяет каждый файл). Клиентские моды (Sodium, Iris и т.п.)
  на сервер не нужны — их в списке нет.

ШАГ 2. Хостинг (my.hosting-minecraft.pro, тариф DEFAULT)
  1) В панели выбери ядро/версию: NeoForge 21.1.265 для Minecraft 1.21.1.
     Запусти сервер один раз и выключи — он создаст свои файлы.
  2) Через «Файлы» (или SFTP, например FileZilla) загрузи на сервер:
        mods\              -> в папку mods (заменить всё)
        config\            -> в папку config (заменить)
        server.properties  -> заменить (там важное allow-flight=true)
        user_jvm_args.txt  -> заменить, если в панели нет своей настройки памяти
  3) eula.txt: eula=true (если панель не сделала сама).
  4) Запусти сервер. Первый запуск долгий (3–6 минут) — это нормально.

ЛЁГКИЙ РЕЖИМ уже включён (config/servercore): сервер сам уменьшает дальность
прогрузки и число мобов, когда не успевает, и объединяет предметы и опыт на земле.

ПАМЯТЬ: тариф DEFAULT = 5 ГБ. Java выделено 4,4 ГБ (-Xmx4400M), остальное —
системе. Если в панели есть поле «память/Xmx» — поставь 4400M, не больше.
Если сервер падает с OutOfMemoryError — уменьши view-distance до 6
в server.properties, а лучше перейди на PERSONAL (7 ГБ) или TRIPLE CORE (9 ГБ).

ШАГ 3. Подключиться
  Клиент: YukiWorld-{VERSION}.mrpack. Сетевая игра -> По адресу -> IP:порт из панели.
