# My To-Do

A clean and simple to-do website with a modern UI.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter by all, active, and completed
- Clear completed tasks
- Dark mode
- Local browser storage for each user

## How it works

This project uses `localStorage`, so every visitor has their own personal task list saved in their browser.
Other users cannot see your tasks.

## Demo

You can host this project with GitHub Pages.

## Tech

- HTML
- CSS
- JavaScript

## Run locally

1. Download or clone the repository
2. Open `index.html` in your browser

## Deploy to GitHub Pages

1. Push the project to a GitHub repository
2. Open `Settings`
3. Go to `Pages`
4. Select `Deploy from a branch`
5. Choose the `main` branch and `/ (root)`
6. Save
